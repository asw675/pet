# 角色视觉方向补充（V1.1 用户确认）

确认于 2026-11-25：桌面陪伴角色为**二次元美少女**，不是现实猫、狗等动物。项目中的 `petId`、`PetRenderer`、宠物馆等工程概念表示可培养、可陪伴的角色实例；保留稳定命名和兼容性，不限制人物必须是动物。游戏化旅行、升级、互动、人格、独立记忆及多角色机制不变。

## 成品美术目标

- 日系轻小说/二次元奇幻美少女，采用清晰的角色剪影、完整人形、差异化服饰、表情和动作。允许魔族、精灵、兽耳等幻想种族的**人形女性**，不采用真正的动物形态作为首批角色默认形象。
- 正常比例的精细全身立绘及未来 Live2D 是成品视觉方向；桌面小尺寸还可使用对应角色的 SD/Q 版序列帧显示模式。当前代码生成的 128px 透明工程图集只用于装载、动作、命中及资源切换验证，不能当作正式画师交付物。
- 角色 ID、版本化资源、职业倾向、人格与实例存档独立：更换画师素材、增加表情、切换序列帧与 Live2D 不迁移业务状态，不让视觉内容决定游戏奖励或权限。
