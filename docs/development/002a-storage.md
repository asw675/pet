# 002A SQLite 事务仓库与版本化存档

日期：2026-11-25

## 范围

新增 `@pet-desktop/app-service` workspace 的数据层及共享端口。使用真实 SQLite，不以 JSON 文件模拟数据库。生产主选 better-sqlite3 未改变；本阶段在开发机用 Node 26.12.1 内置 SQLite 3.54.0 验证 `SqliteConnection` 适配接口，详见 [ADR 0002](../adr/0002-sqlite-poc-driver.md)。

## 实现

- `ports.ts`：领域记录、固定点宠物数值、旅行记录、结算/奖励、命令回执、outbox 与同步事务接口。
- `sqlite-repository.ts`：版本 001 显式 SQL 迁移，迁移历史及校验和固定；未知未来版本、非空未知旧档、外键损坏时拒绝。使用 WAL（真实文件）、FULL 同步、外键、busy timeout、SQLite >=3.51.3 项目版本门槛和实际 FTS5 能力探测。
- 规范表：宠物、状态、成长、偏好、旅行、旅行事实、结算、报告、奖励账本、金币、仓库、CG 解锁、命令回执、outbox 及迁移历史。限定一宠同时间最多一条活跃旅行；冻结旅行快照和已结算状态。此版本只实现旅行来源的奖励，通用非旅行事件来源在未来版本迁移。
- `BEGIN IMMEDIATE` / `COMMIT` / `ROLLBACK` 事务；拒绝嵌套、异步事务、已离开作用域的事务调用。回滚自身失败时将仓库标记为不可用，必须重新启动服务，不继续写库。
- 持久化快照、事件及回执使用版本验证，幂等键发生冲突时拒绝。所有语句参数化；安全整数、枚举、唯一约束与外键共同验证。

## 实测

用户已通过常规终端成功同步新增 workspace；`pnpm-lock.yaml` 真实更新，第三方版本未改变。Node 26.12.1 下仓储专用 Vitest 14/14 通过，覆盖真实文件重启、WAL/FTS5、未来版本拒绝、DDL 迁移回滚、校验和、外键、唯一索引、冻结快照、事实/奖励/回执、事务逸出、错误回滚及回滚失败后的永久不可用。整个项目 TypeScript 检查通过。

## 限制

此为开发机 POC：Electron 打包版实际 native ABI、Windows 真机验证、后续 schema 迁移前一致性备份和完整备份恢复尚未执行。P0-03 不能据此关闭。
