# 004A-R 角色视觉定位修订：二次元美少女

日期：2026-11-25。用户明确桌伴为二次元美少女，而非真实动物，另提供魔族少女参考图。详细确认见 [视觉方向补充](../design/character-art-direction.md)。

本次独立变更将 `star-singer`（星咏）做为绯粉长发、魔角、蓝粉异瞳的暗紫服饰魔族美少女，`fluffy-ranger`（绒绒）做为棕红长发、绿色林地衣装的人形游侠少女，去除动物脸/尾等误解；未知图示也改为人形少女轮廓。内置序列帧和旧 SVG fallback 同时更新。仅为原创 Q 版工程图集，不冒充用户参考图的精细正常比例立绘或最终商业素材。保留 `characterId` 以及动作语义、锚点、几何和业务存档；未发布的旧素材 1.0.0 保存在前序 Git commit。本次资源统一升级到 **1.0.1**，重算完整清单哈希，固定 registry 指向新版本。没有修改宠物领域、数据库或玩家数据。
