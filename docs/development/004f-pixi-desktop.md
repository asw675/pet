# 004F 桌宠 Pixi 渲染与降级

日期 2026-11-25。依据 V1.1 第 17 节，接通锁定的 PixiJS 8.23.0。桌宠窗口按需加载 WebGL 适配器，使用已有角色资源校验、动作时间轴、命中几何和口型。Canvas2D 和 WebGL 使用各自的画布，WebGL 初始化或绘制失败时由 Canvas2D 完成降级。两种画布都无法显示时提供非交互角色头像。角色切换时禁用旧角色命中，直到新资源完成首次绘制。上下文丢失后允许短时间恢复，同一角色的降级画面可在恢复期间继续渲染。

开发机验证：Pixi 附件、Canvas2D、跨窗交接四个 Vitest 文件 49 项通过。生产构建包含按需加载的 Pixi 资源，独立 Main、服务、双 preload 和双 renderer 六入口通过结构检查。模拟 WebGL 端口验证了初始降级、上下文丢失后回退、恢复以及切换期间关闭旧命中；Windows GPU、透明效果、实际跨屏性能仍待真机验收。
