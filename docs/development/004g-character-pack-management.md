# 004G 角色外观资源包导入和版本切换

2026-11-25。实现 V1.1 §17.4 的本地角色外观包安装。设置页可选择数据目录，查看版本，并切换内置包或已安装版本。安装导入需要控制中心操作和原生确认。包只能更新现有角色的外观，角色标识、存档、旅行、事件和 CG 目录独立管理。

Main 校验目录结构、文件类型、大小、SHA-256、版本与客户端兼容性。支持已经接入的序列帧图集或静态 RGBA PNG，保留 PNG 的原始内容凭证。文件验证后写入用户数据目录下的暂存路径，发布到不可变版本目录，再原子更新当前版本指针。旧版保留且可切回，同版本不同文件不能覆盖。桌宠窗口只能读取绑定角色的当前包，现有渲染器在新包首帧成功后换画面。读取或渲染失败时使用应用内置外观。

星咏 1.1.0 静态外观预览位于 `apps/desktop/content-packs/star-singer-1.1.0/`。Windows 测试包装入预览版本，设置页可直接选择。原始序列帧仍为默认并可随时切回。预览使用静态变体，Cubism 运行库和绑定待接入。

验证覆盖导入、重启、切回、同版本冲突、异常清单、目录逃逸、同尺寸内容篡改、preload 权限、真实预览包及渲染读取。应用目录的打包与 Windows 图形交互需按 P0 继续验收。远程发行方签名、跨包去重与按引用回收属于后续缓存与发布流程。
