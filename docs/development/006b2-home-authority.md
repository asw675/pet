# 006B-2 家中调度、离线恢复与实际桌面走动接入

日期：2026-11-25。依据 V1.1 §5、§8、§11 及 [006B-1](006b1-home-rules.md)；不是新一套需求算法。独立子代理分别完成 SQLite v4、应用权威并再次交叉审查，宿主走动由主代理接入。

- 新建 `pet_home_schedules`：每宠持久模拟时钟、活动期限、三种定点小数余数、UTC 互动日/次数/冷却。004 为增量迁移；001–003 校验和保持 `9d3ced6f/a0036d79/519a9ef3`，真实旧档迁移前保留经验证的备份。旧档全部缺少 schedule 时依原存档逻辑水位一次初始化，不伪造之前离线活动；部分缺失或损坏拒绝呈现。新档、领取时同事务建行。
- Service 在同一 authority transaction 模拟 needs、IDLE/WALK/REST/SLEEP/INTERACT、健康恢复与情绪，按定点余额和活动边界计算；只有权威可见变化才增加 revision，纯小数余量允许延后持久化并确定性重算。离线恢复在实际回家时点后开始，AWAY 时不免费回复；召回仅按实际返回时间。旧旅行快照/结算/回执保持原格式及规则。
- `PET_INTERACT` 真正采用纯规则；每日上限、30 秒间隔、REST 渐进恢复、WAKE 唤醒，有独立宠时钟。无奖励的互动不冒充奖励；已有桌宠及控制中心按钮显示正确含义。所有历史 command receipt 保持原样，重试不重复给好感。
- Main 将服务投影的 WALK 接到小窗 DIP 移动（同一次活动至多 96 DIP、24 DIP/s），在当前工作区夹紧、遇边缘换向；光标进入当前/扫过区域 12 DIP 内、用户移动窗口、输入租约、显示布局变化、暂停/隐藏或换代即停。独立复核修复暂时隐藏/恢复反复重走和慢定时器扫过鼠标的风险；不移动鼠标、不发系统输入、不接受 renderer 坐标。走动的效果仍需 Windows 测试。
