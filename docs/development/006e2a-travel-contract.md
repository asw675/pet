# 006E-2A 旅行准备及完整历史投影契约

日期：2026-11-25。对应 V1.1 §6、§18 与 [006E-1](006e1-travel-preparation.md)。独立 `@pet-desktop/contracts/travel`，先闭合路线目录、出发、战报，再接入唯一权威事务。

- 路线目录只提供当前版本的标题/说明/风险/等级/时长/精力/物资/奖励 ID 等作者元数据，物资库存仅提供当前目录所需 ID。出发意图只有 petId、routeId、routeCatalogVersion、最多8种选定物资（每种≤20），客户端不提供 power、seed、时长、价格、路线节点或奖励。
- 预览必须返回同 revision 的资格、闭合阻断理由、确切物资消耗与成本、时长；路线版本错误/未知时无成本。预览不是实际扣款许可，实际交易必须以用户确认为前提重新计算。
- 独立冻结 loadout 契约（catalog 版本、等级、精力、物资、真实属性/战力、三槽实例、强化和历史 bonus），历史旧档可以明确 null，不用当前装备篡改历史。
- 完整 settled 报告持有原来的 5 类 trip-v1 fact、有序序号/时间/归属/归来理由、历史战力、回执、真实奖励；契约检查 ledger 投影与事实累加一致，拒绝失败战斗发放胜利奖励、错宠/错旅程/重复事实、CG 多发。分页每页≤20、scope 与精确行数/时间排序校验；后续服务还需重放原始快照验证。

11/11 契约专项通过、contracts TSC 与原生 Node package self-subpath 导入通过。本步不改变现有旅行入口或任何历史数据，不把契约当作全新路线已上线；真正扣除物资、冻结装备、权威查询与页面在006E-2B/C/D。
