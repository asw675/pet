# 006E-6 职业技能与遗迹首领

日期 2026-11-25。依据 V1.1 §5.3、§6.1。冒险地图上有已知职业的新出发采用 `trip-v3`，冻结职业技能、角色属性、路线和敌人。法师每第三轮触发星辉爆发，游侠首轮触发先机精射，机械助手每三轮从首轮开始触发机巧护防。技能改变伤害或命中和暴击判定。每回合仍消费六次随机数。

星落遗迹原有的核心守护者成为首领遭遇。它的生命不高于一半时，后续攻击触发狂暴。进入星落遗迹仍需要十级和原有补给。真实战报标记首领胜负、职业技能和回合中的实际技能。首领使用节点现有的经验、金币和掉落。首次击败专属称号、剧情、CG 和更多首领仍待开发。

既有 `trip-v1`、`trip-v2` 保留各自的计算方法与事实结构。SQLite 继续使用既有版本字段和快照。开发机验证旅行与战斗领域 27 项、旅行契约 12 项、旅行界面投影 28 项及 SQLite 仓储、应用集成 123 项。覆盖三种技能实际效果、首领胜负、出发后召回、旧版 SQLite 快照重开、结算和恢复回滚、重复读取不重复发奖。Windows 安装版待实测。
