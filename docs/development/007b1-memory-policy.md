日期：2026-11-25，依据 V1.1 §9.2、§19.4。`@pet-desktop/app-service/memory-policy` 独立纯策略、不直接拥有存储事务或模型权限。

- 模型仅产生草案；每条来源必须指向同主人、同 conversation 中真实 COMPLETED USER 消息；先检查身份再读取文本。候选 TTL7天，规范化同 turn 去重，scope 冲突收窄为 PRIVATE，同主人已有活跃事实抑制；无来源扩展和跨会话合并。

- 本地确定性中英文关键词检索、CJK 字及双/三字，pin、相关性、时间、类型和置信度；先授权后索引、最多16条，只返回授权 DTO，不返回其他宠会话。空 query 仅可用置顶。保守敏感字段/控制指令筛查，有误判边界，不是可证明的秘密检测、事实验证或模型隔离；记忆始终是不可信文本。
