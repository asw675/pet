# 007F-1 主动陪伴的存储和授权基础

日期 2026-11-25。提供逐宠开关、独立本地模型许可、静默时间和提醒生命周期的闭合契约与 SQLite 表定义。提醒默认关闭。存储按角色、来源、冷却和每日额度约束记录，对失效的生成请求降级为规则文案。内部会话入口需要可信授权，仅接受本地或 Mock 模型，并要求主宠可见、在家、待机且免打扰未开启。手动聊天可优先取消该宠物正在进行的主动请求。

开发机的 3 项真实 SQLite 存储测试、2 项契约测试和 17 项 AI 控制服务测试通过。存储在测试中应用独立表定义，生产主迁移、触发调度和展示尚待接入，安装包当前不会自动生成提醒或发起主动会话。
