# 007F-2 主动陪伴接入

V1.1 §8.3、§19.3 的主动陪伴接入桌宠与控制中心。SQLite 012 追加逐宠设置、观察与提醒表。旧存档升级时三表均为空，默认关闭。控制中心的「聊天 → 主动陪伴」提供角色开关、本机模型的单独授权、本机时间静默时段，以及按角色分页的未读和历史记录。问候可以标为已读或忽略。

可信宿主只向写入服务发布当前确实可见的待机宠物，变化时立即更新，正常情况下每 15 秒更新。服务读取已提交的旅行归来、持续低精力或最近一次实际互动，检查免打扰、宠物状态、静默时段、近期互动、冷却期、每日限额和来源去重。用户聊天优先于主动生成。守护逻辑和发布逻辑分离，Main 再次校验角色和显示状态后才推送短时文字气泡。气泡不会激活窗口，不接受输入，也不会触发工具、语音或游戏写入。

默认使用各内置角色台词。独立授权后，可使用已绑定且不需要读取凭据的本机回环服务或 Mock 生成简短的角色问候。生成从精确的待处理提醒读触发来源，不发送往期聊天、长期记忆或建议。绑定远程服务、模型不可用或生成失败时保留本地台词。重启时写入者清理悬置任务，转为历史提醒，已经发布的提醒不会再次弹出。

开发验证覆盖真实 SQLite 迁移和权限、实际回家后由 Main/Utility 生成 Mock 问候、静默时段、同源去重、重启恢复，以及桥对相邻角色和宠物窗口的限制。Windows 实际桌面气泡与不同显示器的表现待实机验证。前台其他应用的 Windows 原生全屏识别仍依赖宿主实现。
