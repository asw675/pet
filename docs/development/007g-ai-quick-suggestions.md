# 007G AI 快捷入口建议

V1.1 §10.3、§19.3 的快捷建议接入聊天中心。结构化本机或 Mock 模型在手动聊天时可读取用户允许推荐的已批准快捷入口。发送给模型的字段仅含最多 12 组目标 ID 和显示名称。工作台路径、执行参数、指纹和修订号留在可信层。云模型继续读取原有经授权的会话内容。静默主动陪伴不读取快捷入口。

服务从当前轮次的只读白名单绑定目标名称、修订号、发起角色和有效期，并在保存建议时重新检查。聊天建议页只把角色 ID 和建议 ID 交给 Main。Main 查询建议当前绑定，以原生确认框展示已批准目标的实际位置。确认后校验窗口代次、身份、目标版本和本机文件指纹，启动前要求 SQLite 在同一个事务内复核建议及目标，消费一次性建议记录。来源消息被改动、目标版本变化、授权撤回、建议过期或用户拒绝时均不启动。执行沿用固定的应用、目录和 HTTPS 适配器。

界面回报系统接收、失败、跳过或结果未确认。用户启用本地工作台统计时，结果按建议来源记录。实际系统结果尚未写回模型后续上下文。

开发级验证使用真实 SQLite，覆盖私有目标白名单、目标变更、来源撤销与一次消费。桌面专项使用模拟原生对话框和启动端口，覆盖拒绝、确认期间更换目标、确认期间移除来源、成功执行与防重放。没有执行真实系统启动，相关 Windows 验收仍需设备回归。
