# 007H 授权记忆全文检索

V1.1 §19.4 的长期记忆检索接入 SQLite FTS5。迁移 013 用独立整数键为已确认记忆建立 trigram 索引，并回填现有已确认记录。待确认候选与原始聊天保持在各自的表中。索引使用 contentless 模式保存词项，开启 FTS5 的 secure-delete。新建、改写和删除记忆的触发器与源记录同事务执行，源消息编辑导致的级联删除也会移除词项。整数主键在备份压缩和恢复后保持索引映射稳定。

应用从受限的检索词构造绑定参数，三字符以上由 trigram 匹配，短词走绑定参数的子串匹配。每条查询在 SQLite 内约束当前宠物、共享授权、更新时间和失效时间。保留受限的近期和置顶召回，覆盖已有 Unicode 归一化及词性打分。最终排序沿用只访问授权候选的本地策略，避免全库词频影响其他角色的可见结果。模型只收到现有授权事实投影。仓库在启动、迁移与备份验证时检查映射，写入进程额外运行 FTS 完整性检查。

真实 SQLite 测试覆盖已有记忆回填、中文长短词、跨宠授权、撤回、编辑替换及来源级联删除。还用本机 Node SQLite 3.54.0 和 better-sqlite3 3.53.2 核对 contentless trigram 及可信 schema 关闭时的触发器行为。安装版实机性能、向量扩展、彻底遗忘与备份保留策略另行验证。
