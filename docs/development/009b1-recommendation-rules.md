# 009B-1 本地可解释使用推荐规则

日期：2026-11-25。依据 V1.1 §10.2、§21.4。独立纯模块 `@pet-desktop/domain/recommendation-engine`，只接受应用内 opt-in 已批准目标与粗粒度启动记录，不接收路径、窗口/键盘/其他程序数据，不执行任何目标。

- 未启用直接返回，不读取统计输入。7/30天有界历史，5分钟桶+每次记录的本地 offset，区分工作日/周末和晨/午/晚/夜。仅 ACCEPTED、至少3次独立 MANUAL run 才有资格，重复/失败/建议及场景批量不能自我强化；常见时段、7/30天次数归一化评分，精确证据伴随推荐。
- 已使用上下文目标限 10 分钟，跨目标共现最多每对/本地日计一次，至少3个共用日且各目标达手动阈值方生成可编辑组合（仅稳定收藏ID）；忽略、永久关闭、未批准、未启用、近期已打开排除。当前本地日最多2个建议，稳定 tie-break，不含自动运行指令。实际权威必须持久化 opt-in、历史清理、impression 与冷却。

9/9 纯策略专项及 domain TSC 通过。尚无持久化、实际推荐卡/操作、平台执行；1000条真实性能门槛待部署设备验证。
