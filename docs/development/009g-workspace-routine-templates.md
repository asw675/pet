# 009G 工作台快捷场景模板

2026-11-25，依据 V1.1 §14.3。

工作台的「组合快捷场景」编辑器提供工作、娱乐和学习三个模板。每个模板给出可选收藏的例子，并填入可修改的名称和执行设置。

| 模板 | 收藏举例 | 默认执行设置 |
| --- | --- | --- |
| 工作 | 编辑器、项目目录、协作文档 | 串行，间隔 500 毫秒，失败后停止剩余目标 |
| 娱乐 | 播放器、游戏、娱乐网站 | 有限并行，单个目标失败后继续 |
| 学习 | 笔记、课程网页、资料目录 | 串行，间隔 600 毫秒，失败后继续剩余目标 |

全新草稿的目标列表为空。切换模板会保留草稿中手动添加的收藏及其顺序。用户从已授权且启用的收藏中选择目标后，经原有确认流程保存场景。每次运行仍须单独确认。编辑已保存场景时隐藏模板入口。

工作台投影、服务控制、宿主确认和场景执行共 61 项测试通过，渲染进程 TypeScript 类型检查通过。
