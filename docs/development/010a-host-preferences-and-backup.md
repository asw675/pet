# 010A 宿主设置、SQLite v11 和手动备份导出

日期 2026-11-25。依据 V1.1 第 16、18、21、22 节。数据库 v11 新增独立的宿主设置修订号和窗口位置存储，迁移保留已有旅行、CG、语音、AI 与快捷工作台数据，升级前使用原迁移备份。窗口位置在当前产品仍由 Main 在会话内管理，跨重启位置恢复待接入。

控制中心通过受限 IPC 读写缩放和减少动效。Main 对桌宠窗口重新计算尺寸及工作区边界，renderer 结合应用选择和系统的减少动效配置更新渲染。Windows 固定全局快捷键使用已持久化的开关，实际注册结果逐项显示。开机启动在 Windows 安装版上请求原生确认后修改并读回状态。

手动导出由控制中心打开原生保存对话框，仅 Main 将所选路径交给 SQLite 唯一写入服务。服务对已提交内容生成临时快照，只读重开检查完整性、外键与迁移历史，成功后以独占方式发布，不覆盖已存在文件。取消与失败返回闭合结果。恢复流程仍待开发。

开发机通过 156 项宿主、preload、备份和实际 SQLite 联合专项，包含备份后重开和偏好重启持久化。仓储测试另覆盖真实 v10 数据升级。实际 Electron 窗口、Windows 快捷键和登录启动、目标盘硬链接支持及 DPI 仍需实测。
