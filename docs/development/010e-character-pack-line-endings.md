# 010E 固定角色图集校验字节

日期 2026-11-25。Windows CI 通过依赖、类型检查和应用服务测试后，多个桌宠渲染测试报 `SIZE_MISMATCH`。图集由 Vite 以原始 JSON 字节加载，因此 Windows 的 Git 换行转换会使其与 manifest 的长度和 SHA-256 不一致。仓库对图集文件固定 LF，检出时保留 manifest 已记录的校验字节。包解析和完整性门槛继续使用精确字节。

使用 `core.autocrlf=true` 模拟 Git 检出，三套图集与原清单的长度和哈希均一致。Windows 备份导出仍有单项失败，工作流补充了失败测试的诊断上下文，安装包阶段待下一轮验证。
