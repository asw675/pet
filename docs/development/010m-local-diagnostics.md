# 010M 本地诊断日志和用户导出

2026-11-25。按 V1.1 §22.7 将宿主、应用服务状态、Electron 窗口生命周期及请求异常汇总为本地结构化记录。每条记录有应用版本、协议版本、时间、分级和固定字段。游戏与 AI 请求记录宿主生成的关联编号、类别、结果及耗时。常规请求成功且耗时低于 200 毫秒时不留记录。错误原因来自固定枚举。

日志位于当前应用数据目录的私有子目录，每级旋转三份文件，每份上限 256 KiB。程序启动及运行期间每小时清理超过 14 天的记录。后台写入积压有上限，目录和单文件异常不阻塞应用运行。聊天正文、录音、令牌、提供方自定义字段、窗口标题、用户文件名及本机路径均不进入结构化记录。

用户可在设置的服务状态区域导出 JSON 诊断报告，即便本地业务服务不可用。只有前台控制中心的可信主文档可以打开原生保存对话框。保存前再次确认文档有效，报告重新校验每条记录，清除无效及超期内容。导出使用同目录临时文件及无覆盖发布，需要目的磁盘支持硬链接。渲染进程只获得条目数或固定错误代码。

专项测试覆盖轮转、过期、篡改过滤、重载竞态、业务服务不可用时导出、路径隔离及拒绝覆盖。桌面安装版的原生对话框实测和实际断电条件待验证。
