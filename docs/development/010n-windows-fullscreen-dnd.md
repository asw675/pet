# 010N Windows 前台全屏免打扰

2026-11-25。实现 V1.1 §16.3 的自动全屏免打扰。Windows 助手使用前台窗口、DWM 可见边界和显示器物理坐标识别无边框全屏。普通带标题栏的最大化窗口保持可见。Shell 报告独占 D3D 时尽量定位目标屏，演示模式按全屏处理。助手仅向 Main 返回判定和可选的显示器中心点，且不读取窗口标题、进程身份或画面。

Main 校验随包助手的 SHA-256，通过有界管道低频采样，并要求连续两次确认。默认只隐藏受影响显示器上的桌宠，隐藏后暂停渲染并清除鼠标交互租约、主动气泡和受影响窗口的语音；退出后原窗口以非激活方式恢复。托盘可在本次运行改用全局隐藏。手动免打扰、锁屏和休眠各自独立。前台状态无法判断时静默主动提醒并保留窗口；助手缺失或失败时手动免打扰仍可使用。业务时钟、事件、旅行和结算保持服务端运行。

验证覆盖显示器归属和负坐标、去抖、切回恢复、语音取消、手动免打扰隔离、助手摘要校验、协议长度及命令格式。Windows 本机编译并运行 x64 原生助手，连续两次读取当前普通桌面得到 CLEAR，非法输入得到拒绝。Windows CI 构建也检查助手协议及随包摘要。真实无边框应用、混合 DPI、任务管理器、独占游戏和安全桌面仍需实际设备验收。
