# 010O 全局热键改键

2026-11-25。控制中心的「设置 → 全局热键」提供改键、恢复默认和实际注册状态。打开控制中心、显示或隐藏桌宠、恢复鼠标交互继续默认使用 Ctrl + Shift + P、H 和 I。改键可选 Ctrl + Shift、Ctrl + Alt 或 Ctrl + Alt + Shift，搭配字母、数字或 F1–F12。三项动作使用独立组合键。恢复默认后保存，使用同一套注册和冲突检查。

Windows 启用热键时，Main 先尝试取得新组合的系统注册，再请存档服务保存。若组合被占用，设置页标注对应动作，此次改键不会替换已经生效的组合。关闭全局热键期间可修改已保存的组合，重新启用时检查系统是否可注册。启动时读取 SQLite v14 的已保存组合，并独立报告当前实际注册状态，便于定位重新启动期间出现的冲突。旧存档迁移后沿用原有三个组合及启用状态。

自动测试覆盖注册冲突、存档失败回滚、保存确认后启用新组合、动作交换、输入校验和存档重开。实际 Windows 环境中与第三方软件抢占同一组合后的提示，以及重启后的按键行为，需要设备验收。
