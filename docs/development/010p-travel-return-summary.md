# 010P 免打扰后的旅行结算汇总

2026-11-25，依据 V1.1 §14.2 T09。Main 根据相邻的已提交旅行快照记录同一角色、同一旅行从进行中到已结算的变化。手动免打扰、全屏、锁屏或休眠期间合并待提示数量，持续静默。恢复后等待一秒合并同批返回，通过 Windows 托盘提示结算数量，禁用提示音并尊重操作系统静默时间。已显示的条目同时保留在托盘菜单，用户可打开控制中心查看战报。

提示状态在本次桌宠会话中保存。首次载入或服务重启后的历史结算仍可在旅行页查看。提示没有存档写权限，也不参与旅行时间、奖励和事件结算。

自动测试覆盖多宠结算合并、旧投影及重复版本过滤、已显示和待显示数量的隔离。宿主专项模拟 Windows 全屏及手动免打扰同时启用的完整恢复路径。实际 Explorer 提示及用户系统通知设置需要 Windows 界面验收。[Electron 托盘通知接口](https://www.electronjs.org/docs/latest/api/tray#traydisplayballoonoptions-windows)
