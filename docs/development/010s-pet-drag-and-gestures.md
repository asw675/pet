# 010S 桌宠直接拖动与模型交互

2026-11-25。按住角色的有效区域或名称手柄可拖动窗口。小幅移动仍可以触发普通点击。拖动开始后，宿主接管指针采样和显示器工作区夹紧，保留鼠标抓住模型时的偏移。拖动会停止本次自动走动，通过结束事件和超时恢复常规穿透。放下后用现有窗口锚点保存位置。

角色点击区区分头部和身体。头部沿用摸头互动，身体播放交互反馈。Cubism 预览可读取对应动作，也会处理跟视、拖动时的动作及光标离开后的复位。已有静态立绘可轻微随光标移动并响应点击。 [Cubism Framework 参数接口](https://github.com/Live2D/CubismWebFramework/blob/develop/src/model/cubismmodel.ts)

位置恢复同时修复了冷启动的竞争。已保存的位置可以替换窗口创建期间的临时默认位置。读取缩放偏好前按存档中的窗口尺寸恢复锚点，避免小窗口靠近屏幕边缘的位置被按默认尺寸夹紧。

Windows 隔离 Electron 验证了短按头部、按住角色拖动、中途停顿、松手、两档比例及重启恢复。100% 和 50% 的新存档均精确恢复放下的位置。跨屏负坐标和显示器边缘的夹紧通过宿主自动化。全仓类型检查、生产构建和 2455 项测试通过，3 项按平台条件跳过。
